# Project Documentation

## Project Title

PyPDF Studio – PDF Editor Application

## Objective

To develop a desktop-based PDF Editor using Python with a modular architecture and graphical user interface.

## Architecture

- Presentation Layer (CustomTkinter GUI)
- Service Layer
- PDF Processing Layer (PyMuPDF)
- Image Processing Layer (Pillow)

## Implemented Features

1. Merge PDFs
2. Split PDF
3. Rotate Pages
4. Delete Pages
5. Extract Text
6. Images to PDF

## Libraries Used

- PyMuPDF
- Pillow
- CustomTkinter

## Error Handling

- Try-except blocks
- Input validation
- File selection validation

## Future Enhancements

- Password protection
- Watermark
- PDF Preview
- PDF to Images

## Conclusion

The application successfully demonstrates modular design, OOP principles, and GUI-based PDF manipulation using Python.
