# PyPDF Studio – PDF Editor Application

## Overview

PyPDF Studio is a Python-based desktop application that provides common PDF editing features through a user-friendly graphical interface built with CustomTkinter.

## Features

- Merge multiple PDF files
- Split PDF by page range
- Rotate PDF pages (90°, 180°, 270°)
- Delete selected pages
- Extract text from PDF files
- Convert images (PNG/JPG) to PDF

## Technologies Used

- Python 3.11+
- CustomTkinter
- PyMuPDF (fitz)
- Pillow

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python main.py
```
